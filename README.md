# Ragi Ruchulu website

A static bilingual website for Ragi Ruchulu in Jadcherla, Telangana.

## Included pages
- Home
- Our Menu
- About Us
- Why Millets?
- Gallery
- Contact & Location

## Features
- Mobile-first responsive design
- English and Telugu language switch
- WhatsApp ordering with pre-filled messages
- Phone ordering link
- Interactive cart with quantity controls
- Automatic subtotal and parcel charge calculation
- Local business SEO and structured data
- Sitemap and robots.txt
- Google Maps embed

## Local preview
Open `index.html` directly in a browser or run a simple static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
